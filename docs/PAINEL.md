# Painel do site PromoPost — guia rápido

Acesse **/admin** (ex.: `https://promopost.com.br/admin`) com seu e-mail e senha.
Tudo o que você salvar aparece no site em instantes.

## Onde está cada coisa

| Quero mudar… | Vá em |
|---|---|
| Banners do slider da Home | **Home → Banners do topo** |
| Programar um banner para entrar/sair do ar | Abra o banner → **Entra no ar em / Sai do ar em** |
| Cards de anunciantes (Em destaque / Mais ofertas) | **Home → Anunciantes** (campo **Seção** define onde aparece) |
| Banners do "Apoio Institucional" (todas as páginas) | **Compartilhado → Apoio Institucional** |
| Menus, logo, botões "Anuncie"/"Cadastro" | **Compartilhado → Cabeçalho** |
| Rodapé (menu, Instagram, QR Code, copyright) | **Compartilhado → Rodapé** |
| Os 4 blocos com ícone (Fortaleça, Venda mais…) | **Compartilhado → Benefícios** (vale para Home e Anuncie) |
| Títulos "EM DESTAQUE" e "MAIS OFERTAS" | **Compartilhado → Títulos das vitrines** |
| E-mail que recebe os formulários, assunto, mensagens | **Compartilhado → Formulários** |
| Textos e banner de uma página | **Páginas → (Sobre, Anuncie, Contato, Cadastro…)** |
| Política de Privacidade / Termos de Uso | **Páginas → Política de Privacidade / Termos de Uso** |
| Título e descrição no Google | Em cada página, grupo **SEO (Google)** |

## Dicas
- **Imagens:** envie no mesmo tamanho das atuais (banners do topo 1920×619, banners de página 1400×410,
  cards 500×300). A imagem é publicada exatamente como enviada.
- **Ordem:** número menor aparece primeiro.
- **Tirar do ar sem apagar:** desmarque **Ativo**.
- **Excluir imagem:** só é possível se ela não estiver em uso. Se estiver, o painel avisa onde; troque lá e exclua depois.
- **Esqueci a senha:** na tela de login, informe seu e-mail e siga o link recebido. O link vale por 1 hora.
- **Texto alternativo** das imagens ajuda no Google e na acessibilidade — descreva a imagem em poucas palavras.
